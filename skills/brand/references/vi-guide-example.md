# VI 指南示例

品牌名称：AIX
视觉核心概念：数字古典主义与建筑几何

1. 标志设计（Logo Design）
主标志构型：等边三角形外部轮廓，内部由两条 45 度斜线交汇形成的 X 型结构支撑。
设计逻辑：A 代表架构（Architecture）与顶点，X 代表交叉（Intersection）与无限。整体呈现为抽象的微型纪念碑，象征绝对精准与智性秩序。
视觉特征：等线宽线条，直角切割边缘，无圆角处理，强调工业级冷峻感。

2. 标准字体（Logotype）
字体名称：AIX Typeface（定制化黑体）
设计特征：全大写字母，宽字间距（Kerning）。
A：去横杠，仅保留上升支架，与图形标志呼应。
I：等宽长方形，顶部与底部水平切齐。
X：中心交汇点微调，确保视觉重心平衡。

3. 品牌色彩系统（Color Palette）
绝对黑（Absolute Black）：CMYK 0,0,0,100，哑光质感。用于主视觉背景及高端面料。
纯粹白（Pure White）：CMYK 0,0,0,0，高亮度。用于标志及核心指令文字。
手术刀灰（Surgical Grey）：CMYK 0,0,0,15，金属冷调。用于辅助线、网格及技术参数标注。

4. 标识系统扩展（Graphic System）
精密网格：基于 12x12 数字化网格系统，所有视觉元素对齐网格交点。
坐标标注：在包装或成衣细节处，使用微型单色字体标注地理坐标或生产批次代码，强化黑盒引擎的工业溯源感。
线性语言：使用 0.25pt 极细实线作为分割符，模拟建筑蓝图严谨性。

5. 男装应用规范（Menswear Application）
主标：高频无缝压胶工艺，黑色哑光硅胶材质，置于后颈中心或左袖口。
洗标：长条形极简设计，仅保留图标与二维码，代码化洗涤说明。
包装：全黑炭黑特种纸盒，标志采用 UV 透明亮油工艺，通过光影折射显现。
辅料：定制钛金属拉链，拉头激光刻印 X 型符号。

6. 视觉质感定义（Texture and Finish）
纹理：拒绝自然褶皱，追求面料挺括感与平整度。
光泽：低反射率，吸光性表面，强调技术隐匿的低调美学。
